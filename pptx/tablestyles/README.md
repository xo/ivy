# The table styles of PowerPoint

`medium-style-2-accent-1.xml` is the table style "Medium Style 2 - Accent
1", the default table style of PowerPoint. It is a copy of the element
`a:tblStyle` of `ppt/tableStyles.xml` in the file
`test-data/slideshow/table_test2.pptx` of Apache POI, at the commit
8d9b40ac4cb62b1c61759c900fb422abfeac4367. PowerPoint wrote that file.

`LICENSE` and `NOTICE` are the files of `legal/` of Apache POI at the same
commit, byte for byte. The copy is under the Apache License 2.0.
