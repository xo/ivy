# D40. msppt does not read PowerPoint 95

Status: Decided.

MS-PPT does not describe PowerPoint 95, and PowerPoint 2024 does not open
it either. A reader would rest on the study of a few files. Question 16 of
`PLAN.md` asked whether `msppt` reads it.

On 2026-11-18 the maintainers decided that `msppt` gives `ErrUnsupported`
for a file of PowerPoint 95, and the backlog drops the item.
